## 需求要点

### 用户明确要求

1. 交付一个 HTML 页面。
2. 页面内容使用 SVG 绘制。
3. 主体为一只鹈鹕骑自行车，鹈鹕与自行车应组成同一骑行场景。
4. 表现形式为二维动画，需要呈现动态效果。

### 为使任务可验收而细化的行为

- 鹈鹕应具备可识别的外形特征，例如长嘴和明显的喉囊；观众能判断它是鹈鹕。
- 自行车应有可识别的双轮、车架、车把和骑行支撑部件。
- 鹈鹕姿态与自行车相互匹配，身体、脚与车把或踏板的位置能够表达“正在骑车”。
- 动画应表达持续骑行，例如车轮转动与踩踏动作；仅让整张静态图片平移不足以体现骑行。
- 动画中的鹈鹕与自行车应保持关联，避免明显脱离、穿插错误或运动断裂。
- 用户打开页面后应能够直接看到主体与动画。

## 范围

### 本任务的核心范围

- 一个用于展示动画的 HTML 页面。
- SVG 绘制的鹈鹕、自行车，以及表达骑行动作所需的动画。
- 支撑观看主体的必要页面布局。

### 非必要扩展

用户未要求账户、后端、数据存储、音效、复杂交互、游戏规则或多页面功能，这些不纳入当前核心需求。背景装饰、文字说明、播放控制等可以在设计阶段评估，但不作为本任务必须交付的功能。

### 建议交付约束（供设计阶段评估）

- 优先考虑可直接打开的单个 HTML 文件，使用内联 SVG，减少资源缺失导致的展示问题。
- 优先使用浏览器原生能力，避免为简单展示引入不必要的工程或依赖。
- 建议在常见桌面和手机视口保持主体完整可见。
- 建议考虑减少动态效果偏好，提供适宜的静态或减弱动画表现。

上述内容属于建议，不将用户未指定的文件组织方式、技术栈或兼容范围视为已确认的硬性要求。

## 风险

- 普通鸟类轮廓可能不足以表达鹈鹕，需要在后续设计中突出嘴部和喉囊特征。
- 车轮、踏板与脚部运动若缺乏协调，可能造成骑行姿态不自然；后续应通过实际动画观察验证。
- SVG 构图或缩放处理不当可能裁切主体；目标视口应在设计阶段明确，并在测试阶段验证。
